# CafeFlow OS - Restaurant Management System

## Overview

CafeFlow OS is a console-based **Restaurant Management System** developed in **C++** using **Object-Oriented Programming (OOP)** principles. The application provides separate interfaces for **Customers** and **Owners**, allowing customers to browse the menu and place orders while enabling owners to manage menu items. The system features a simple, user-friendly interface with color-coded menus for an improved console experience.

## Features

### Customer

* View the restaurant menu categorized by food type.
* Place orders by adding items to the shopping cart.
* View items in the cart along with the total cost.
* Checkout and generate the final bill.

### Owner

* View the complete restaurant menu.
* Add new food items with custom categories and prices.
* Remove existing menu items.
* Dynamically manage the restaurant menu during program execution.

## Technologies Used

* **Language:** C++
* **Programming Paradigm:** Object-Oriented Programming (OOP)
* **Libraries:** STL (`vector`, `map`), `iomanip`, `windows.h`, `conio.h`
* **Platform:** Windows Console

## OOP Concepts Implemented

* **Classes and Objects**
* **Inheritance**
* **Polymorphism**
* **Encapsulation**

## Data Structures

* **Vector** for storing menu items and customer carts.
* **Map** for grouping food items by category.

## Default Menu Categories

* Burgers
* Drinks
* Sides
* Main Course
* Desserts

## How to Run

1. Open the project in a C++ IDE such as Visual Studio.
2. Build and compile the project.
3. Run the executable.
4. Select either **Customer** or **Owner** mode from the main menu.
5. Follow the on-screen instructions to interact with the system.
